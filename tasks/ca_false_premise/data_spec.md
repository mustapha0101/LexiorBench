## Purpose
Identifier si une question juridique contient une prémisse factuelle ou légale erronée selon le droit québécois ou canadien.

## Question format
**Input:** Une question ou affirmation juridique présentant potentiellement une prémisse incorrecte.
**Output:** Prémisse correcte | Prémisse erronée (avec explication)

## Answer type
classification_and_generation

## Legal sources
- **CCQ**
- **Lois fédérales canadiennes**
- **Jurisprudence CSC**

## Do not use
- Droit américain
- a2aj/canadian-laws
- Données de a2aj/canadian-laws
