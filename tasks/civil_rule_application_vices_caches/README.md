# civil_rule_application_vices_caches

**Type de raisonnement :** rule-application · **Domaine :** droit civil · **Langue :** français

Application de la garantie de qualité (art. 1726 C.c.Q.) à des situations
factuelles. Le texte de l'article est fourni dans le gabarit de la tâche; le
modèle doit déterminer si la garantie contre les vices cachés peut être
invoquée (gravité, caractère caché, antériorité, connaissance de l'acheteur).

**Étiquettes :** Oui / Non

**Sources :** Code civil du Québec, art. 1726 (texte législatif public). Situations factuelles originales et fictives.

> ⚠️ Les réponses de référence sont des ébauches en attente de validation par un
> juriste (voir `docs/annotation-workflow.md`).
