## Purpose
Identifier la juridiction compétente (Cour du Québec, Cour supérieure, Cour fédérale, etc.) pour une affaire décrite.

## Question format
**Input:** Un scénario décrivant un litige ou une demande judiciaire.
**Output:** Nom de la juridiction compétente et base légale.

## Answer type
classification_and_generation

## Legal sources
- **C.p.c. RLRQ c C-25.01, art. 34-38 (compétence matérielle)**
- **Loi sur les Cours fédérales, LRC 1985 c F-7**
- **Loi sur la Cour suprême, LRC 1985 c S-26**

- Système judiciaire américain
- a2aj/canadian-laws
