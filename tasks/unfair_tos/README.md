# unfair_tos

**Type de raisonnement :** interpretation · **Domaine :** public · **Langue :** en

Given a clause from a terms-of-service contract, determine the category the clause belongs to.

**Étiquettes :** Arbitration / Choice of law / Content removal / Contract by using / Jurisdiction / Limitation of liability / Other / Unilateral change / Unilateral termination
