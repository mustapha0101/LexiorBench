## Purpose
Extraire les valeurs numériques juridiquement significatives (délais, montants, seuils) d'un texte légal québécois ou canadien.

## Question format
**Input:** Un extrait de loi, contrat ou décision judiciaire contenant des valeurs numériques.
**Output:** Liste structurée des valeurs numériques avec leur signification juridique.

## Answer type
generation

## Legal sources
- **CCQ (prescription, délais, seuils)**
- **LNT RLRQ c N-1.1 (durées légales)**
- **Lois fédérales**

- Droit américain
