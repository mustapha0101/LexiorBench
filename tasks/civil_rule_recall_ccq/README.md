# civil_rule_recall_ccq

**Type de raisonnement :** rule-recall · **Domaine :** droit civil · **Langue :** français

Rappel du contenu du Code civil du Québec : énoncés Vrai/Faux portant sur les
obligations (arts. 1375, 1385, 1594), la prescription (arts. 2917-2918, 2925),
la capacité (arts. 4, 153, 156, 163-165), la garantie de qualité (art. 1726),
l'autorité parentale (art. 600) et les régimes matrimoniaux (art. 432).

**Étiquettes :** Vrai / Faux

**Sources :** Code civil du Québec (texte législatif public). Énoncés originaux.
