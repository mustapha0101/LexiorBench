# public_rhetorical_jugement

**Type de raisonnement :** rhetorical-understanding · **Domaine :** droit public · **Langue :** français

Compréhension rhétorique d'extraits de jugements en droit administratif :
identifier si l'extrait énonce la norme de contrôle, expose les prétentions
d'une partie, applique le droit aux faits, ou constitue la conclusion
(dispositif) du jugement.

**Étiquettes :** Norme de contrôle / Prétentions d'une partie / Application aux faits / Conclusion

**Sources :** Tous les extraits de jugements sont **fictifs** et rédigés pour cette tâche; aucun extrait de décision réelle ni de doctrine protégée.

> ⚠️ Les réponses de référence sont des ébauches en attente de validation par un
> juriste (voir `docs/annotation-workflow.md`).
